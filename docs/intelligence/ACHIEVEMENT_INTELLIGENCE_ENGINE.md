# Achievement Intelligence Engine v1

محرك TypeScript نقي يحول بيانات الألعاب والإنجازات والنشاط إلى توصيات قابلة للتفسير. لا يقرأ repositories، ولا يستدعي Tauri أو Steam، ولا يكتب إلى SQLite، ولا يولد نصوص واجهة نهائية.

## الاستخدام

```ts
import { analyzeAchievementJourney } from "../../src/intelligence/index.ts";

const analysis = analyzeAchievementJourney({
  games,
  achievements,
  activity,
  now: "2026-07-27T12:00:00Z"
});
```

القيمة `now` قابلة للحقن لتثبيت الاختبارات والملخصات. عند غيابها يستخدم وقت التنفيذ.

## المخرجات

- `rankedGames`: كل الألعاب الصالحة مرتبة حسب Journey Score.
- `journeyCards`: بطاقة واحدة كحد أقصى لكل لعبة، مرتبة بالأولوية.
- `nextAchievement`: أفضل إنجاز تالٍ أو `null`.
- `achievementDna`: نمط اللاعب والثقة والمقاييس.
- `weeklyInsights`: ملخص آخر سبعة أيام ومقارنة الأسبوع السابق.
- `diagnostics`: العناصر المتجاهلة وأعلام نقص البيانات.

الألعاب المخفية والمكتملة تظهر في `rankedGames` لأغراض التشخيص بقيمة `eligible=false` ودرجة صفر، ولا تدخل Continue Journey.

## Journey Priority Score

الدرجة هي مجموع خمسة أجزاء ثم تُقيد بين 0 و100:

| الجزء | الحد | القاعدة |
|---|---:|---|
| Completion | 35 | 0–49% حتى 10 نقاط، 50–79% حتى 25، 80–99% حتى 35 |
| Remaining achievements | 25 | إنجاز واحد 25، اثنان 22، ثلاثة 18، حتى خمسة 14، حتى عشرة 8، أكثر 3 |
| Recency | 20 | ≤2 يوم 20، ≤7 أيام 16، ≤14 يومًا 11، ≤30 يومًا 6، ≤90 يومًا 2 |
| Status | +10/-15 | Playing +10، Backlog -5، Abandoned -15 |
| Favorite | 5 | Favorite +5 |

اللعبة بلا إنجازات لا تحصل على نقاط Completion أو Remaining؛ يمكنها فقط الاستفادة من الحداثة والحالة والمفضلة. وقت اللعب الكبير لا يملك وزنًا مستقلًا.

القيم غير الرقمية و`NaN` تصبح قيمًا آمنة، والتواريخ غير الصالحة تعامل كغير معروفة. النتيجة تعيد `breakdown` كاملًا.

## Journey Cards

الحدود معرفة في `constants.ts`:

| النوع | الشرط الأساسي |
|---|---|
| `oneAchievementLeft` | بقي إنجاز واحد |
| `rareOpportunity` | عدد الإنجازات النادرة المتاحة أكبر من المفتوحة |
| `almostFinished` | الإكمال 80–99% |
| `continueJourney` | Playing خلال 14 يومًا، أو Journey Score ≥35 |
| `worthReturning` | الإكمال أكبر من 50% وعدم نشاط 30 يومًا |
| `forgottenAdventure` | عدم نشاط 90 يومًا |
| `recentlyCompleted` | 100% وآخر نشاط خلال 14 يومًا |
| `noAchievementsYet` | إجمالي الإنجازات صفر |

ترتيب القواعد مقصود: الإكمال الحديث، غياب الإنجازات، إنجاز واحد، فرصة نادرة، قرب الإكمال، العودة، المغامرة المنسية، ثم الاستمرار. البطاقة تعيد `reasonCode` و`translationKey` و`translationParams` بدل النص.

في v1 يستخدم `lastPlayedAt` كأفضل proxy متاح لحداثة الإكمال؛ عند توفر تاريخ اكتمال حقيقي يجب استبداله.

## Next Achievement

يُستبعد:

- المفتوح.
- المخفي.
- الإنجاز التابع للعبة غير صالحة أو غير موجودة.

الأوزان:

- تقدم قريب من الهدف: حتى 45 نقطة.
- ندرة قابلة للتحقيق بين 1% و10%: 25 نقطة.
- ندرة 10–30%: 14 نقطة.
- أقل من 1%: خصم 8 نقاط لتجنب توصية شبه مستحيلة بلا سياق.
- Journey Score للعبة: حتى 25 نقطة.
- توفر معلومات تقدم أو ندرة: 5 نقاط.

لا يقدّر المحرك زمن الإنجاز؛ `estimatedTimeMinutes` دائمًا `null` في v1.

## Achievement DNA

الحد الأدنى ثلاثة ألعاب مرئية. أقل من ذلك يعيد `balanced` مع `insufficient_game_sample` وثقة لا تتجاوز 0.2.

- `completionist`: متوسط إكمال ≥75% ونسبة ألعاب مكتملة ملحوظة.
- `explorer`: ثماني ألعاب مبدوءة أو أكثر.
- `rareHunter`: ثمانية إنجازات نادرة أو أكثر، مع تصاعد الثقة.
- `focusedPlayer`: أربع ألعاب مبدوءة أو أقل و70% من الوقت في لعبة واحدة.
- `collector`: مكتبة ≥12 لعبة ونسبة غير مبدوءة ≥45%.
- `casualPlayer`: وقت لعب إجمالي منخفض (≤600 دقيقة في البيانات المتاحة).
- `balanced`: لا يتجاوز نمط آخر حدًا موثوقًا.

هذه شخصية وصفية للبيانات المتاحة وليست حكمًا ثابتًا على المستخدم. تعاد المقاييس و`reasonCodes` لتفسير النتيجة.

## Weekly Insights

تستخدم أيام UTC لتجنب اختلافات DST:

- إجمالي دقائق اللعب.
- الإنجازات المفتوحة.
- عدد الألعاب المميزة عندما تتوفر IDs، أو مجموع العدادات عند توفر أرقام فقط.
- الأيام النشطة.
- اليوم الأكثر نشاطًا، بوزن 15 دقيقة مكافئة لكل إنجاز عند كسر التعادل.
- نسبة تغير وقت اللعب مقارنة بالأيام 8–14 عند توفرها.
- Streak ينتهي باليوم الحالي ويمكن أن يتجاوز سبعة أيام إذا توفرت 14 يومًا.
- مفاتيح ترجمة للملخصات المحتملة.

إذا لم توجد بيانات للأسبوع السابق تكون المقارنة `null`. وإذا كان السابق صفرًا والحالي موجبًا تعاد 100 بدل قسمة غير صالحة.

## مثال مبسط

```ts
const input = {
  now: "2026-07-27T12:00:00Z",
  games: [{
    gameId: "game-1",
    title: "Official Game Title",
    status: "playing",
    completionPercent: 95,
    totalAchievements: 20,
    unlockedAchievements: 19,
    lastPlayedAt: "2026-07-26T18:00:00Z"
  }]
};
```

الناتج يتضمن درجة مرتفعة مع 25 نقطة للإنجاز المتبقي وبطاقة `oneAchievementLeft`. اسم اللعبة يمرر إلى `translationParams` ولا يُترجم داخل المحرك.

## Diagnostics

- `ignoredInvalidGames`: Game ID فارغ أو مكرر.
- `ignoredInvalidAchievements`: Achievement ID فارغ/مكرر أو Game ID غير معروف.
- `insufficientDataFlags`:
  - `dna_game_sample`
  - `next_achievement_data`
  - `weekly_activity_data`

لا يسجل المحرك أي بيانات في Console.

## البيانات المطلوبة مستقبلًا من Steam

- Achievement schema الكامل لكل لعبة.
- حالة الفتح وتاريخه.
- Global unlock percentage.
- إحصاءات تقدم رقمية عندما توفرها المنصة فعليًا.
- تاريخ دقيق لوصول اللعبة إلى 100%.
- Rare available count محسوب من بيانات حقيقية.

لا يجب اختراع وقت متوقع أو درجة صعوبة أو تقدم جزئي عندما لا يوفر المصدر هذه البيانات.

## حدود v1

- قواعد ثابتة وليست تعلمًا آليًا.
- لا تخصيص للأوزان حسب المستخدم.
- لا تحليل جلسات لعب أو أنواع ألعاب.
- DNA يعتمد على عينة البيانات المحملة، وليس تاريخ الحساب الكامل بالضرورة.
- `lastPlayedAt` proxy مؤقت لبطاقة Recently Completed.
- مقارنة الأسبوع تعتمد على playtime، وليس جودة الجلسة.
- لا دمج مع Dashboard أو Notifications في هذه المرحلة.

## ما لا يجب أن يفعله المحرك

- الوصول إلى SQLite أو repositories أو APIs.
- ترجمة النصوص أو أسماء الألعاب والإنجازات.
- تسجيل IDs أو نشاط المستخدم.
- تنفيذ Side effects أو جدولة إشعارات.
- اختراع بيانات ناقصة.
- إخفاء breakdown أو سبب القرار عن المستهلك.

## التحقق

يشغل:

```bash
npm run test:intelligence
```

Validation suite الحالية تغطي: الإدخال الفارغ، لعبة بلا إنجازات، إنجاز واحد متبقٍ، المكتملة والمخفية، التاريخ والقيم غير الصالحة، Completionist، Collector، Rare Hunter، نقص البيانات، النشاط الأسبوعي الفارغ، ومقارنة 14 يومًا.
