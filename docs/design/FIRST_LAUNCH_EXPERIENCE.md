# First Launch Experience v1

تظهر التجربة عندما تكون `onboardingCompleted` غير مفعّلة. تُحمّل الإعدادات من المستودع قبل العرض، ويؤدي الزر النهائي وحده إلى حفظ الإكمال؛ إغلاق التطبيق قبل ذلك يبقي التجربة مطلوبة.

يتكون التدفق من Welcome، Personalization، Connect Steam، ثم Library Sync / Completion. تغييرات اللغة والمظهر تُطبّق وتُحفظ عبر Settings Service الحالي. إعادة التشغيل من Settings تغيّر مفتاح الإكمال فقط ولا تمس المكتبة أو الاتصال أو بقية التفضيلات.

يستخدم الاتصال Steam Connection Service الحالي. حقل API Key عابر وغير محفوظ في state الأبوي أو SQLite، ويُفرّغ بعد الطلب. تستخدم المزامنة Steam Library Sync Service الحالي، ولا تبدأ مزامنة الإنجازات. الفشل لا يمنع دخول التطبيق.

الخلفية تنفيذ WebGL أصلي ببرنامج وشيدر ومخزن واحد. تعتمد على أبعاد الحاوية وDPR أقصاه 1.5، وتتوقف عند إخفاء المستند أو فقدان التركيز، وتحذف الموارد والمستمعات عند الفك. عند غياب WebGL أو تفعيل `prefers-reduced-motion` يبقى CSS gradient ثابتًا قابلًا للاستخدام.

تستخدم الواجهة عناصر دلالية، تركيزًا ظاهرًا، أزرارًا حقيقية، وRTL/LTR من نظام الترجمة. لا يعتمد فهم الخطوات على الحركة.

حدود v1: لا مزامنة خلفية أو تلقائية، لا مزامنة إنجازات تلقائية، لا endpoints جديدة، لا telemetry، ولا تخزين لمفتاح API.
