## RA-002 — Windows console window

- Status: **Passed after fix**.
- Root cause: the Rust binary entry point did not select the Windows GUI subsystem for non-debug builds.
- Before fix: PE subsystem `3` (`Windows Console`).
- After fix: PE subsystem `2` (`Windows GUI`).
- NSIS install returned exit code 0.
- The installed application remained responsive with the `Achievement Nexus` main window.
- No new `conhost` process appeared while the installed application was running.
- NSIS uninstall returned exit code 0 and removed the temporary program directory.
- Regression coverage: `test:quality` now requires the release-only `windows_subsystem = "windows"` attribute.
- RA-002 is closed. RA-001 remains open and the overall package decision remains NO-GO pending independent-profile acceptance.
