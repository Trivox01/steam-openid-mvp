# Achievement Nexus 0.1.0-beta.1

> Closed Beta — for invited testers only.

## Overview

This is the first installable Windows beta of Achievement Nexus, a local desktop application for exploring a Steam game library, tracking achievement progress, and identifying useful next goals.

## Included

- Steam account connection using SteamID64 and a Steam Web API key held in process memory only.
- Steam Library Sync with idempotent local updates.
- Steam Achievement Sync with clear partial, unsupported, and retryable states.
- Game Library in grid and list layouts with search, filters, sorting, and density controls.
- Game Details with dynamic artwork, achievement discovery, search, filters, and progress summaries.
- Achievement Journey recommendations derived from locally available data.
- Statistics 2.0 with completion, activity, playtime, efficiency, and data-quality insights.
- English and Arabic interfaces with LTR and RTL support.
- Dark, Light, and System themes.
- Keyboard navigation, visible focus, reduced-motion support, accessible dialogs, and image fallbacks.

## Known limitations

- Closed Beta builds are unsigned. Windows SmartScreen may show an Unknown Publisher warning.
- The Steam Web API key is not retained after the application exits and must be entered again for a later sync session.
- Some Steam games expose no achievement schema; others may return partial achievement data.
- No cloud sync, Achievement Nexus account, telemetry, analytics, or automatic updater is included.
- Startup and tray preferences are stored but their Windows system integration is not active in this version.
- Export and destructive data deletion actions are previews only where the interface explicitly says so.

## Reporting issues

Send reports through the channel provided by the Closed Beta coordinator. Include the application version, Windows version, reproduction steps, expected result, actual result, and a screenshot when useful. Never include a Steam Web API key.
